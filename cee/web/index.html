Working 1 — Induction

Something went wrong that the engine has never seen before, so it writes down what it learned instead of guessing twice.

  1. Detect. A channel leaves its healthy band. The engine ranks the deviating channels and computes a total residual.
  2. Generalise. For each deviating channel it writes one comparison whose threshold sits between the healthy band and the observation — e.g. rpm > 123. The rule covers a region of telemetry, not one reading, and a nominal frame can never satisfy it.
  3. Choose a remedy. Every primitive action is forward-simulated. The one predicted to leave the smallest residual wins, and the projected number is stored as that rule's promise.
  4. Commit. Predicate + action become a new rule in the knowledge graph with its own confidence counter, and the action is dispatched immediately.

Working 2 — Recall

The same fault happens again, so the engine reuses what it already knows and then checks whether that knowledge was any good.

  1. Match. Every stored predicate is evaluated against the current telemetry. Rules that fit are ranked by confidence × specificity.
  2. Apply. If the best match clears the confidence floor it is trusted: its action is dispatched to the actuators, which measurably change the telemetry.
  3. Verify. Two frames later the same channels are re-measured and compared against the rule's own projection — not an arbitrary threshold.
  4. Reinforce. Reality matched the prediction, so confidence rises; it did not, so the rule is demoted and, once demoted far enough, stops being trusted.
Symbols evolve, primitives don't

Rules are invented and revised at runtime. The vocabulary of motor and compute actions is fixed and interpretable.

Judged, not assumed

Every action is scored by forward simulation and then held to that same prediction afterwards. Bad models lose confidence.

Never learn from your own fix

Induction is blocked while an intervention is in force, so rules describe the rover instead of the engine's mitigation.

Memory survives restart

The knowledge graph is persisted to disk, so accumulated experience keeps reinforcing across sessions.
